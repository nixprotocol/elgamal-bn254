# Security

If you discover a security vulnerability in this project, please report it responsibly.

## Reporting

Email **security@nixprotocol.com** with:
- Description of the vulnerability
- Steps to reproduce
- Impact assessment

Please do not open a public GitHub issue for security vulnerabilities.

## Scope

This library handles ElGamal encryption, homomorphic ciphertext operations, zero-knowledge proofs (DLEQ, equality, apply-pending), and encrypted memo (ECDH + AES-256-GCM). Vulnerabilities in key generation, encryption, decryption, proof generation/verification, or serialization are in scope.
